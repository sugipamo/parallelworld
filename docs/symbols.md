# 記号と既存概念への対応

`docs/spec.md` v0.2 と `pw/kernel.py` が実際にやっていることを記号で書き、数学の既存概念に対応させる。
厳密さは問わない。各対応に「一致」（定義がそのまま当てはまる）か「類比」（形が似ているだけ）を付けた。

## 1. 記号

| 記号 | 意味 | 実装 |
|------|------|------|
| ℋ, ℱ, 𝒢 | 知識命題、Lean命題、接続仮説の集合 | 原子 `H:` `F:` `G:` |
| 𝒜 = ℋ ⊔ ℱ ⊔ 𝒢 | 原子全体 | `State.atoms` |
| Γ | 固定された形式的前提 | ツールチェーン＋`Gamma.lean`＋公理の許可リスト |
| Π ⊆ Thm(Γ) | 検証済みの証明の有限集合 | `proof` イベント |
| g : H ⇝ F | 接続仮説 g ∈ 𝒢 が H と F を結ぶ | `links` |
| T = T_link ∪ T_Π | 世界が満たす論理的制約 | `infer` の `ok` マスク |
| Ω = Mod(T) ⊆ 2^𝒜 | 可能世界 | 残った行 |
| ⟦φ⟧ = { w ∈ Ω : w ⊨ φ } | 論理式 φ の外延 | `fm.evaluate` |
| 𝒦 ⊆ Δ(Ω) | 制約を満たす事前分布の集合 | `rows` |
| L_e : Ω → [0,1] | 証拠 e の尤度 | カタログの `[a, b]` |
| 𝒦∣E | 証拠で更新した分布の集合 | LPの正規化行 |
| P̲(φ), P̄(φ) | 𝒦∣E 上の μ(⟦φ⟧) の最小と最大 | `infer` の `lo`, `hi` |

## 2. 形式層 ― リンデンバウム代数（一致）

Lean命題を証明可能な同値で割ったものがリンデンバウム＝タルスキ代数。

```
𝓛_Γ = Prop / ~_Γ        F₁ ~_Γ F₂  ⇔  Γ ⊢ F₁ ↔ F₂
```

`Classical.choice` を許しているのでブール代数になる（許さなければハイティング代数）。`prove` の5種類は、この代数の中の関係にそのまま対応する。

| `prove` | 𝓛_Γ での意味 |
|---------|-------------|
| `iff` F₁ F₂ | [F₁] = [F₂] |
| `implies` F₁ F₂ | [F₁] ≤ [F₂] |
| `contradiction` F₁ F₂ | [F₁] ∧ [F₂] = ⊥ |
| `holds` F | [F] = ⊤ |
| `not` F | [F] = ⊥ |

システムが知っているのは 𝓛_Γ 全体ではなく、Π が与える関係だけ。つまり持っているのは「生成元 ℱ と関係 Π で表示されたブール代数」𝔹_Π で、真の代数へは全射がある。

```
𝔹_Π ↠ 𝔹_Π′ ↠ ⋯ ↠ ⟨ℱ⟩ ⊆ 𝓛_Γ        （Π ⊆ Π′）
```

証明を追加することは、この商の列を一段進めること。v0.1 §7 の「形式的同一性」は [F₁] = [F₂] のこと。

## 3. 可能世界 ― ストーン双対（一致）

ブール代数 𝔹 の点（2への準同型、超フィルター）が可能世界。有限なので単に 𝔹 のアトム。

```
Ω_Π = Hom(𝔹_Π, 2)
```

商 𝔹_Π ↠ 𝔹_Π′ は双対側で包含 Ω_Π′ ⊆ Ω_Π になる。v0.2 で「証明は Ω の絞り込みであってベイズ更新ではない」としたのはこの形。

| 状態変化 | 代数側 | 世界側 |
|----------|--------|--------|
| 証明の追加 | 𝔹 を商で割る | Ω を部分集合に縮める |
| 証拠の観測 | 何も変わらない | Ω 上の測度を重み付けし直す |

証明されていない定理に確率を置けること（論理的全知を仮定しないこと）は、𝔹_Π が 𝓛_Γ より粗いことに対応する。

## 4. 確率 ― 確率論理と不精確確率（一致）

v0.1 §3 の ⟦H⟧_E = Σ_{w⊨H} μ_E(w) は、文に確率を与える標準的な定義（ガイフマン、ニルソンの確率論理）。

v0.2 は μ を一つに決めず、線形制約を満たす μ の凸集合 𝒦 を状態とする。これは**クレーダル集合**（リーヴァイ、ウォーリーの不精確確率）で、`infer` は下側確率・上側確率。

```
P̲(φ) = min_{μ ∈ 𝒦∣E} μ(⟦φ⟧)        P̄(φ) = 1 − P̲(¬φ)
```

「いくつかの事象の確率が与えられたとき、別の事象の整合的な確率は区間になり、線形計画で求まる」はデ・フィネッティの確率の基本定理（ブール、ハイルペリン）。`infer` はこれをそのまま解いている。

v0.1 §6 の max(0, a + b − 1) はフレシェ不等式で、この定理の最小の例。

## 5. 接続仮説 ― 情報源の信頼性モデル（一致）

g : H ⇝ F が世界に課す制約は一つ。

```
⟦g⟧ ⊆ ⟦H ↔ F⟧
```

事前分布への制約は三つ。

```
μ(g) = γ                        接続の基準率
μ(F ∣ g) = μ(F) = π             形式化の正しさと F の真偽は無関係
μ(H ∣ ⋀ ¬gᵢ) = π_H              どの接続も外れているとき、H は基準率に戻る
```

これはベイズ認識論の**証言の信頼性モデル**（ボーヴェンス＝ハートマン）と同じ形。「情報源が信頼できれば報告は事実と一致し、できなければ報告は事実と無関係に基準率で出る。信頼性と事実は独立」。ここでは F が「報告」、g が「信頼できる」にあたる。

通信路で言えば、確率 γ で恒等、確率 1−γ で入力と無関係な出力を返す混合通信路（類比）。

## 6. 知識の同一性 ― 測度代数の距離（一致）

二つの命題の距離を、食い違う世界の確率で定義する。

```
d_μ(A, B) = μ(⟦A⟧ △ ⟦B⟧) = 1 − μ(A ↔ B)
```

これは測度代数のフレシェ＝ニコディム距離（擬距離）。𝒦 上の上限 d̄ = sup_μ d_μ も三角不等式を満たす。すると二種類の同一性は同じ物差しの上に並ぶ。

| | 記号 | 由来 |
|---|------|------|
| 形式的同一性 | d̄(F₁, F₂) = 0 | Lean：[F₁] = [F₂] |
| 接続 | d̄(H, F) ≤ 1 − P̲(g) | ⟦g⟧ ⊆ ⟦H ↔ F⟧ |
| 意味的同一性 | d̄(H₁, H₂) が小さい | 上の二つから導く |

v0.1 §6 は三角不等式そのもの。

```
d̄(H₁, H₂) ≤ d̄(H₁, F₁) + d̄(F₁, F₂) + d̄(F₂, H₂) ≤ (1 − 0.9) + 0 + (1 − 0.8) = 0.3
```

最終原則もこの形で読める。Leanは中央の項を 0 にするが両端の項には触れず、両端の不確実性は中央の 0 を動かさない。

ほかの関係は順序と測度の単調性になる：[F₁] ≤ [F₂] なら μ(F₁) ≤ μ(F₂)、[F₁] ∧ [F₂] = ⊥ なら μ(F₁) + μ(F₂) ≤ 1。

## 7. 証拠 ― 仮想証拠・コピュラ・一般化ベイズ則

**尤度（一致）。** 証拠 e は対象原子 X の真偽だけに依存する尤度を持つ。効くのは比だけなので、パールの**仮想証拠**と同じ。

```
μ′(w) ∝ L_e(w) μ(w)        L_e(w) = a（w ⊨ X）, b（w ⊭ X）
```

**証拠どうしの依存（類比）。** 同じ対象への証拠 e₁,…,e_k の同時尤度は、周辺が決まっていて結合が未知。結合の仕方はコピュラで、v0.2 が認める範囲は独立コピュラ Π と共単調コピュラ M の間。

```
完全に重複:  P(e₁ ∧ ⋯ ∧ e_k ∣ X) = min aᵢ        （M、フレシェ上界）
独立:        P(e₁ ∧ ⋯ ∧ e_k ∣ X) = ∏ aᵢ          （Π）
```

v0.1 の「独立を仮定しない」を最も弱く読むとフレシェ下界 W まで許すことになるが、それだと証拠が増えるほど下界が下がる。v0.2 は「正の依存だけ」に制限した。同一出自の証拠を一つに数えるのは、集合としての冪等性。

**更新（一致）。** 分布の集合を要素ごとに条件づける。ウォーリーの**一般化ベイズ則**。

```
𝒦∣E = { μ(· ∣ E) : μ ∈ 𝒦 }
```

比の最適化なので線形分数計画になり、チャーンズ＝クーパー変換で線形計画に落とす（実装は Σ L·y = 1 の正規化行）。

**区間の拡大（一致）。** 条件づけで区間が広がる現象は**ダイレーション**（サイデンフェルド＝ワッサーマン）として知られている。最初の実走で下界が 0.905 から 0.890 に下がったのはこれ。

## 8. 状態 ― 結び半束（類比）

状態はイベントの集合 S で決まり、推論は S の関数。

```
infer : 𝒫(Events) → 区間        merge(S₁, S₂) = S₁ ∪ S₂
```

証明の追加は制約の共通部分、証拠の更新は尤度の積なので、どちらも可換で、重複は冪等。つまり状態は結び半束で、エージェント間の知識共有は結び（CRDT でいう grow-only set）。

ただし確率は S について単調ではない（証拠は上げも下げもする）。単調なのは Ω の縮小だけ。また `ground` は `claim` の後、という因果順序は必要。

## 9. 置いている仮定

1. **接続の意味** ⟦g⟧ ⊆ ⟦H ↔ F⟧。
2. **信頼性と事実の独立** μ(F ∣ g) = μ(F)。
3. **証拠の局所性** e は対象原子を通じてのみ世界に依存する（マルコフ条件）。
4. **証拠は正に依存** コピュラは Π と M の間。
5. **成分間の無関連性** 連結でない成分は互いの区間を動かさない（ウォーリーの epistemic irrelevance）。Leanが真偽を決めた F は定数で、成分をつながない。

1 は定義、2〜5 はモデルの選択で、v0.1 にはなかったもの。

## 10. 対応が崩れている所

**定理はすべて ⊤ に潰れる。** リンデンバウム代数は証明の中身を忘れるので、証明済みの F₁, F₂ は必ず [F₁] = [F₂] = ⊤。実走で出た「`clamp` と `bound` の同値は空虚」はこれ。距離で言えば、真な命題どうしは最初から d = 0。

潰れないのは、閉じた命題ではなく**述語**（自由変数を持つ式）の代数。文脈 x : A の上のリンデンバウム代数 𝓛_Γ(x : A) では、P(x) と Q(x) は定理でなくても比べられる（ローヴェアのハイパードクトリンのファイバー）。これを使うと主張は二つに分かれる。

```
H  ⇝  (P, a)        F = P(a)
P ∈ 𝓛_Γ(x : A)      仕様（述語）
a : A               対象（プログラムのモデル）
```

| 同一性 | 記号 | `clamp` / `bound` の例 |
|--------|------|------------------------|
| 同じ仕様 | [P₁] = [P₂] in 𝓛_Γ(x : A) | どちらも「lo 以上 hi 以下」 |
| 同じ対象 | Γ ⊢ a₁ = a₂（外延的等しさ） | lo ≤ hi の範囲で同じ値を返す |
| 同じ知識 | 両方 | |

これは提案で、まだ実装していない。

**Γ が動く場合。** Γ ⊆ Γ′ なら 𝓛_Γ ↠ 𝓛_Γ′ で古い関係は保たれる。Γ を縮めたり定義を変えたりした場合は対応が切れ、Π は無効になる。
